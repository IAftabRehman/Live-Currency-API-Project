### 📋 Project Description

The **Live Currency API ** app is a **Flutter-based mobile application** that provides **real-time currency conversion** between over 150 currencies using a reliable and free exchange rate API.

Whether you're a traveler, investor, or just want to keep track of the global market, this app allows you to quickly convert one currency into another using the **latest exchange rates** — all from your mobile device.

With features like **base/target currency selection**, **instant conversion**, and **live rates**, Live CurrencyX offers a clean, fast, and responsive experience.

---

### 🧰 Features

- 🌍 **Supports 150+ Currencies** – Convert between all major world currencies.
- 📶 **Live Exchange Rates** – Real-time data fetched from [ExchangeRate-API](https://www.exchangerate-api.com/).
- 🔽 **Dropdown Currency Selectors** – Easily pick base and target currencies.
- 🧠 **State Management with Provider** – Efficient architecture using `provider` package.
- 🎯 **Simple, Responsive UI** – Clean and modern Flutter UI for smooth experience.

---

### 🔧 Tech Stack

- **Flutter** – Cross-platform mobile app framework
- **Dart** – Programming language for Flutter
- **Provider** – State management solution
- **HTTP Package** – For calling the API
- **ExchangeRate-API** – Free API for real-time currency data
- **JSON Parsing** – To handle API responses

### 🏁 Getting Started

To get started with this project, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/IAftabRehman/Live-Currency-API-Project.git
    ```

2. Navigate to the project directory:
    ```bash
    cd Live-Currency-API-Project
    ```

3. Install dependencies:
    ```bash
    flutter pub get
    ```

4. Run the app:
    ```bash
    flutter run
    ```
